## What you can do with AI Coworker

Delegate real engineering workflows with full human control, safety, and auditability.

<CardGrid stagger>
  <Card title="Approval-Gated Executions" icon="approve-check">
    The implemented task flow requests human approval before sandbox execution. Review the approved input and resulting changes; do not treat approval as a guarantee of correct output.
  </Card>
  <Card title="Isolated Sandbox Containers" icon="laptop">
    The configured runtime uses Cloudflare Sandbox containers. Isolation boundaries and operational limits require review; no claim that arbitrary malicious code cannot escape is implied.
  </Card>
  <Card title="Account-Owned Deployment" icon="seti:cloudflare">
    Deployment is intended for your Cloudflare account. Repository data and credentials cross the configured service boundaries; review [Security](/docs/security/) before use.
  </Card>
  <Card title="Automated Issue Triage & Bug Fixing" icon="puzzle">
    GitHub webhook automation paths are implemented. Results depend on configuration and still require human review; the repository has no recorded cloud acceptance run.
  </Card>
  <Card title="Interactive Diff Review" icon="magnifier">
    Review run results and diffs in the dashboard; available surfaces depend on configuration. PR publication is optional and requires GitHub credentials.
  </Card>
  <Card title="Autonomous Scheduled Sweeps" icon="setting">
    Automation trigger types are implemented and unit-tested. Configure and validate each integration in your own account; implementation is not evidence of successful cloud operation.
  </Card>
</CardGrid>
